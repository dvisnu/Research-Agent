Our research agent is built specifically for computer science and machine learning research. A user gives it a research question or a rough idea, and can optionally upload relevant papers. It returns two linked outputs. The first is a Novel Evidence Report, which proposes a new research idea and rates how novel it is. The second is an experiment plan in which every element is backed by, and traceable to, published research. The agent does not run experiments; carrying out the plan is left to the researcher. Internally it is a Python pipeline built with LangGraph, used from the command line.

The agent first turns the user's input into a short research brief: the core problem, a few angles from which to search, and keywords. It then searches Semantic Scholar and arXiv and follows citations, both the papers each result builds on and the papers that later built on it. The results are ranked by relevance. Most papers are kept at the abstract level, and the most relevant ones are read in full, with every sentence given a fixed address (paper, section, sentence) so it can be cited precisely later.

From the papers read in full, it builds a knowledge graph. A language model extracts each paper's task, methods, datasets, metrics, results, limitations and assumptions, and every extracted claim must quote its source sentence. Code checks that each quote really exists in the paper and discards anything that doesn't match, which keeps hallucinations out of the graph. Using this graph, the agent maps what has and hasn't been studied, for example which methods have been tested on which datasets. It finds research gaps in three ways: from limitations the authors themselves state, from combinations that haven't been tried, and from papers whose findings contradict each other.

It then generates candidate ideas from the strongest gaps, by fixing a known limitation, combining existing methods, or borrowing a technique from another area. Each idea is checked with a fresh search, so it isn't judged only against the papers that inspired it, and is compared with the closest existing papers one at a time. It is rated on a 1–5 scale: duplicate, minor variation, new combination, open research gap, or new direction. When the evidence is unclear, the agent assigns the lower rating, and it always reports potential novelty rather than proven novelty. Ideas that score too low are adjusted and checked again.

For the chosen idea, it writes an experiment plan covering the hypothesis, method, datasets, baselines, metrics, ablations, expected results and risks. Most of these come straight from what the closest papers actually used and reported. Each element records where its information came from, how the agent arrived at it, and why it was chosen over the alternatives. A separate model then checks whether each cited source genuinely supports its claim, and flags anything unsupported.

Every step is logged, so any recommendation can be traced back through the agent's reasoning to the exact paper section it came from. We will evaluate the system automatically against an LLM-only baseline and a standard retrieval (RAG) baseline, measuring both how novel its ideas are and how reliable its citations are.
